# Tools Agent 006

This agent (`tools_agent_006`) is for testing MCP (Model Context Protocol)
Toolset with stdio transport.

## Purpose

-   Demonstrates how to configure and use `McpToolset` with stdio server
    connection
-   Tests integration with the official everything demo MCP server
    (@modelcontextprotocol/server-everything)
-   Validates stdio transport mechanism for MCP tools
-   Uses official MCP demo server with simple tools (add, echo) that require no
    authentication or external APIs
