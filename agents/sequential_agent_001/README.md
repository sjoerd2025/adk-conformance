# Sequential Agent 001

This agent (`sequential_agent_001`) demonstrates the use of a `SequentialAgent`.

## Purpose

-   Tests the workflow of a `SequentialAgent` which executes a series of sub-agents in a predefined order.
-   This example includes sub-agents for finding flights, hotels, and summarizing a trip.
-   Verifies that state and information are passed correctly between sub-agents in the sequence.
